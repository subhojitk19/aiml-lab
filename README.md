# AI/ML Lab 🚀

A collection of Artificial Intelligence and Machine Learning experiments, assignments, and projects developed as part of my AI/ML learning journey.

## 📌 About

This repository contains implementations of various AI and Machine Learning algorithms, including:

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning Models
- Deep Learning Projects
- Model Evaluation
- Feature Engineering
- Data Visualization
- Python Programming for AI/ML

## 🛠️ Technologies Used

- Python 3.x
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras
- Jupyter Notebook

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/subhojitk19/aiml-lab.git
```

### Navigate to the project

```bash
cd aiml-lab
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```
